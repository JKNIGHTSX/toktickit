# Lab 3 — Part 9.3 Visual Inspection Checklist

## Inspection scope

This checklist compares the frontend with [`ui-spec.md`](./ui-spec.md), especially:

- **Sections 2–3:** Zen Green design tokens, role badges, application header, and role-specific navigation.
- **Sections 4.1–4.5:** login and first-login password screens, staff queue and ticket detail, administrator user management, and state feedback.
- **Section 6:** desktop (`>= 992px`), tablet (`768–991px`), and mobile (`< 768px`) layouts; minimum 44×44px touch targets; 2px green keyboard focus rings; and WCAG AA text contrast.

The frontend imports Bootstrap in [`main.tsx`](../../client/src/main.tsx); most TokTickIT-specific colors and layout rules are inline in components. The Lab 3 visual QA uses 1200×800, 768×1024, and 375×667 viewports.
